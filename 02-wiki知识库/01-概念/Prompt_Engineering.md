## 核心定义

提示工程是通过任务说明、背景、示例、约束和反馈，引导语言模型产出所需结果或执行行动的方法。现有资料共同强调明确任务、输出与上下文；课程及模型文档还表明，减少歧义比单纯加长提示更重要，提示必须适配模型能力和实际输入上下文。

## 核心方法

- **明确目标：** 说明角色、受众、语气、范围、格式和验收要求；对于工具任务，明确希望实施的动作及其边界。解释要求背后的原因，帮助模型理解取舍。
- **少样本提示（Few-Shot Prompting）：** 提供相关且多样的输入输出配对，展示格式和边界。课程以工单标题为例；Anthropic 剪藏建议 3–5 例，并强调避免示例引入无关模式。
- **结构化输出（Structured Output）：** 明确字段、数据形状和是否允许解释文字。课程展示 JSON 提示，Anthropic 文档讨论格式指示。提示中的格式样例只是预期说明，不能据此认定具备程序级校验保证。
- **访谈式提示（Interview Style Prompting）：** 当任务背景尚不完整时，让模型先询问关键缺失信息。课程建议逐题问答，并示范在信息足够时结束提问，避免无止境澄清。
- **推理与自检：** 对需要推理的任务，可要求检查解题依据和结果；是否显式要求逐步推理应随模型能力而定。Anthropic 剪藏对 Claude 4.6 更偏好总体目标、adaptive thinking 和验收标准，手动思维链作为补充。
- **迭代与提示链（Prompt Chaining）：** 根据输出缺口修订；需要检查中间产物时，按“大纲→正文→评价→修订”等步骤执行。把上一阶段的必要产物传给下一阶段，避免遗漏事实。

以上方法主要来自 [[prompt-engineering-full-course]] 与 [[anthropic-prompting-best-practices]]；它们在本页集中维护，不为每项技巧重复建立孤立页面。

## Gemini 文档的补充

[[gemini-api-prompt-design-strategies]] 强烈建议使用少样本示例，并要求格式一致、内容多样、通过实验确定数量。与 Anthropic 的 3–5 例建议相比，两者都重视示例，但没有足够依据确立跨模型固定数量；“始终加示例”应保留为该文档的建议。

该文档区分提示中的简单 JSON 格式说明与复杂架构的 API 结构化输出功能。它还展示通过输出前缀进行内容补全，以及改变措辞、任务形式、输入顺序进行迭代。提示中的补全内容与特定 API 的 assistant 消息预填充不是同一机制，不能据此推翻 Claude 文档的接口弃用说明。

文档列出温度、topK、topP、停止序列和输出上限，但参数可用性依模型而异；这些设置需要结合任务试验。关于温度为零的确定性、提高温度处理后备回答等表述尚未在本库验证，不写成通用保证。

## 知识冲突

### 正向描述与负面约束

课程 22:04–24:16 认为明确禁止项有时比只描述目标更有效；Anthropic 剪藏的“Communication style and verbosity”优先建议描述期望行为，例如用连贯段落表达格式偏好。两者并非所有情境下直接矛盾，但对默认策略的推荐不同。

编译建议：先说明希望得到的结果，再添加确有必要的排除项；对具体模型与任务比较输出，不把“负面指令总更有效”或“禁止项从不有效”写成规律。这是对两份材料的综合判断，尚无本仓库实验验证。

### 普遍拆步骤与按需拆步骤

课程 31:22–32:10 普遍推荐将复杂任务分解成顺序提示；Anthropic 剪藏“Chain complex prompts”指出自适应推理模型常可内部完成多步骤，但审查中间产物和强制管线时仍适合显式串联。差异涉及模型能力和外部控制需求，不能脱离条件比较优劣。

编译建议：必须人工审查或需要独立验证的阶段保留显式检查点；其余步骤是否拆开，依据任务成功率、成本和时延评估。

Gemini 文档的“将提示分解为多个组成部分”也推荐拆指令、串联提示和并行汇总，为普遍拆分一侧补充了来源；其 Gemini 3 部分又说明模型具备内部思考，复杂工作流编排不等于要求输出完整推理过程。

### 强制规划与减少过度思考

Gemini 文档“Agentic Workflows”的深度智能体模板要求每次行动前分析依赖、风险、假设及完整性，并强调持久恢复；Anthropic 文档“Overthinking and excessive thoroughness”提醒强模型可能探索过度，建议减少笼统的反复思考要求。前者也明确承认准确率与时延、词元成本的权衡。

编译判断：这是不同模型与任务下的策略张力，应按任务后果、依赖复杂度和真实失败情况设置规划深度，不能把强规划模板直接当作所有模型的默认最优提示。本次未运行两种策略的对照实验。
