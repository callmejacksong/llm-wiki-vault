# 查询知识库

遵循仓库根目录 `AGENTS.md`。回答以实际读取的 Wiki 内容为依据。

1. 先读取 `02-wiki知识库/index.md`，定位相关实体、概念、来源摘要和综合笔记。
2. 完整读取相关页面，并沿相关双链补充上下文。索引无匹配时用 `rg` 或可用的文件搜索工具检索 `02-wiki知识库/`，避免将未入索引误判为不存在。
3. 必要时只读追溯页面 `sources` 中的原始资料，包括历史归档。路径失效时明确报告，不假装已读原文。
4. 综合回答，在相应结论或段落末尾使用 `[[页面名称]]` 标注依据。区分来源事实、推断和未解决的知识冲突；不要虚构页面引用。
5. 本地没有相关内容时明确说明“本地知识库中未找到相关内容”。若补充通用知识或外部资料，单独标明来源，不能包装为用户已有笔记。

## 保存与日志

- 用户要求“查询并保存”“形成综合笔记”等时，在 `02-wiki知识库/04-综合/` 创建或更新 kebab-case 命名的综合页，遵循 `AGENTS.md` 的 frontmatter 和 `## 关联连接` 要求，并更新索引与相关页面的关联。
- 用户只提问时直接回答，不自动新增综合页；确有保存价值可在回答后建议保存。
- 查询结束后在 `02-wiki知识库/log.md` 追加 `query` 记录，列出依据页面及是否保存；用户明确要求完全只读时不写日志。

```markdown
## [YYYY-MM-DD] query | 问题主题
- **输出**: 即时回答未保存；依据 [[Prompt_Engineering]]
```
